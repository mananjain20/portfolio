# Manan Jain Portfolio (Vite + React)

Personal portfolio built with React and Tailwind CSS. Showcases skills, projects and contact information.

Manan.dev — Personal Portfolio

A clean, minimal portfolio website built with React.

Tech Stack
- React
- Tailwind CSS (CDN used for development convenience in `index.html`)
- Vite
- GitHub REST API

Features
- Hero section with profile photo
- Skills showcase
- Live GitHub projects
- Contact form
- Responsive design

Getting started

1. Install dependencies

```bash
cd /Users/mananjain/Documents/Portfolio2.0
npm install
```

2. Start dev server

```bash
npm run dev
```

The dev server will print a local URL (usually http://localhost:5173). Open it in your browser.

Notes
- This repository was converted from a static HTML portfolio into a Vite + React app. The main app lives in `src/App.jsx`; feel free to refactor into components.
- Tailwind is included via CDN for quick development; consider installing Tailwind properly for production builds if desired.

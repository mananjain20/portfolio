# Manan Jain Portfolio (Vite + React)

Personal portfolio built with React and Tailwind CSS. Showcases my skills, projects and contact information.

Manan.dev — Personal Portfolio

A clean, minimal portfolio website built with React.

Tech Stack
- React
- Tailwind CSS (CDN for dev in `index.html`)
- Vite
- GitHub REST API

Features
- Hero section with profile photo
- Skills showcase
- Live GitHub projects
- Contact form
- Responsive design

Getting started

1. Install dependencies

```bash
cd /Users/mananjain/Documents/Portfolio2.0
npm install
```

2. Start dev server

```bash
npm run dev
```

The dev server will print a local URL (usually http://localhost:5173). Open it in your browser.

Notes
- Tailwind is loaded via CDN in `index.html` for development convenience.
- This repo is a single-file React mount (`src/App.jsx`) converted from an original static HTML. Feel free to split into components.
